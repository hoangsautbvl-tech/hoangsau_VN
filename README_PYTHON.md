# Phiên bản Python

Phiên bản này thay phần Scratch/TurboWarp bằng một server Python và giao diện học tập trong `public/python`.

Chạy:

```powershell
.\run_python_app.ps1
```

Mở:

```text
http://127.0.0.1:9100
```

Đường dẫn bản đồ gốc vẫn dùng lại trong app Python:

```text
http://127.0.0.1:9100/map
```
